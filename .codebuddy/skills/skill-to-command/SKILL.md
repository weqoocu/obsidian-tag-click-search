# Skill 转快捷指令

本技能将已有的 skill 转换为快捷指令，放置到 `.codebuddy/commands` 目录下的对应分类文件夹中。

## 核心功能

将 `.codebuddy/skills/` 目录下的技能转换为 `.codebuddy/commands/` 目录下的快捷指令，快捷指令作为技能的入口点，告诉 AI 调用哪个 skill。

## 命令分类规则

根据 skill 的功能特点，将生成的快捷指令放入对应的分类目录：

| 分类 | 目录名 | 适用场景 |
|------|--------|----------|
| 生成类 | `create/` | 创建、生成新内容 |
| 修复类 | `fix/` | 修复问题、Bug |
| 查询类 | `get/` | 获取、查询信息 |
| 同步类 | `sync/` | 同步、更新数据 |
| 分析类 | `analyze/` | 分析代码、数据 |
| 工程化类 | `工程/` | 构建、发版、部署 |
| 优化类 | `optimize/` | 优化、改进代码 |
| 需求类 | `需求/` | 需求管理相关 |

## 执行流程

### 步骤 1：读取 commands 目录结构

首先读取 `.codebuddy/commands/` 目录，了解现有的分类文件夹结构。

### 步骤 2：分析 skill 内容

读取目标 skill 的 SKILL.md 文件，分析：
- skill 的名称和描述
- skill 的主要功能
- skill 的触发场景

### 步骤 3：确定分类目录

根据 skill 功能匹配最合适的分类目录：
- 如果已有合适的分类目录，使用现有目录
- 如果没有合适的分类目录，根据命名规则创建新目录

### 步骤 4：生成快捷指令文件

在对应分类目录下创建快捷指令 `.md` 文件。

### 步骤 5：更新映射表

更新 `.codebuddy/skills-docs/SKILLS_COMMAND_MAP.md` 文件，添加新创建的 skill 与快捷指令的映射关系。

## 快捷指令模板

```markdown
---
description: "{emoji} {简短描述} - {功能说明}"
argument-hint: "[custom-prompt]"
---

# {emoji} {指令标题}

{一句话说明此指令的作用}

## 📋 执行流程

| 步骤 | 操作 | 说明 | 必须 |
|-----|------|------|-----|
| 1️⃣ | **{步骤名}** | {步骤说明} | ✅ |
| 2️⃣ | **{步骤名}** | {步骤说明} | ✅ |

### 详细说明

#### 1️⃣ {步骤名}
调用 `{skill-name}` skill 执行 {具体操作}。

**注意**：直接读取并执行 skill 文件内容，而不是调用 `use_skill` 工具。

---

## 🎯 关键规则

### ✅ 必须执行
- {规则1}
- {规则2}

### ❌ 严格禁止
- {禁止项1}
- {禁止项2}

### 额外补充说明
$1  !!IMPORTANT

---

**开始执行...**
```

## 命名规范

快捷指令文件命名规则：
- 使用中文或英文，简洁明了
- 反映指令的核心功能
- 示例：`发送消息.md`、`生成测试报告.md`、`分析代码.md`

## 示例

### 输入
将 `wecom-sender` skill 转换为快捷指令

### 输出
在 `.codebuddy/commands/create/` 或新建的 `notify/` 目录下创建 `发送企微消息.md`：

```markdown
---
description: "📨 发送企微消息 - 通过企业微信机器人发送群消息通知"
argument-hint: "[消息内容或通知类型]"
---

# 📨 发送企微消息

通过企业微信机器人 Webhook 发送群消息通知。

## 📋 执行流程

| 步骤 | 操作 | 说明 | 必须 |
|-----|------|------|-----|
| 1️⃣ | **读取 skill** | 读取 `wecom-sender` skill 内容 | ✅ |
| 2️⃣ | **确认消息内容** | 与用户确认要发送的消息 | ✅ |
| 3️⃣ | **发送消息** | 按照 skill 指令执行发送 | ✅ |

### 详细说明

#### 1️⃣ 读取 skill
读取 `.codebuddy/skills/wecom-sender/SKILL.md` 的内容并按照其指令执行。

**注意**：直接读取并执行 skill 文件内容，而不是调用 `use_skill` 工具。

---

## 🎯 关键规则

### ✅ 必须执行
- 读取 wecom-sender skill 完整内容
- 按照 skill 中的指令格式发送消息

### ❌ 严格禁止
- 不要跳过 skill 的执行步骤
- 不要自行构造 webhook 请求，必须按 skill 指令执行

---

**开始发送企微消息...**
```

## 映射表格式

更新 `.codebuddy/skills-docs/SKILLS_COMMAND_MAP.md` 时，按以下格式添加映射记录：

```markdown
## Skills 与快捷指令映射表

| Skill 名称 | 快捷指令 | 分类 | 说明 |
|-----------|---------|------|------|
| `skill-name` | `/指令名称` | 分类目录 | skill 和指令的简要功能说明 |
```

### 映射表字段说明

- **Skill 名称**：skill 文件夹名称，使用代码格式
- **快捷指令**：快捷指令名称，以 `/` 开头
- **分类**：快捷指令所在的分类目录
- **说明**：一句话描述该 skill/指令的功能

## 注意事项

1. **快捷指令是入口**：快捷指令本身不实现具体功能，而是指导 AI 读取并执行对应的 skill
2. **保持简洁**：快捷指令应简洁明了，核心是告诉 AI 去调用哪个 skill
3. **分类合理**：选择最匹配的分类目录，必要时创建新目录
4. **格式统一**：遵循快捷指令模板格式，保持一致性
5. **更新映射表**：每次创建快捷指令后，必须更新 SKILLS_COMMAND_MAP.md
